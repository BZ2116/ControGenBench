# ControGenBench

ControGenBench 是一个面向争议感知和风险敏感文本生成的评测基准。与传统安全基准将所有争议内容视为有害不同，ControGenBench 区分**建设性分歧**（丰富公共讨论）和**有害内容**（需要干预）。

## 概述

ControGenBench 评测语言模型是否能够：

1. **识别争议性主张**并评估其建设性分歧潜力
2. **选择适当干预方式** — 从保留有价值争议到改写有害内容
3. **执行局部修订** — 降低风险同时保留作者立场、语义含义和讨论潜力
4. **校准自动指标** — 确保自动评分与多维度人工判断一致

本基准以**主张（claim）**为基本单元，聚焦文本中可定位的单条争议性断言，而非整体评估完整文档。

## 任务定义

| 任务 | 描述 | 评测指标 |
|------|------|----------|
| 主张属性预测 | 预测分歧潜力、建设性分歧潜力、有害性、证据风险和作者立场 | 标注者间一致性、分布匹配度 |
| 风险感知动作选择 | 选择保留、先核验、限定、容纳反方、降温、改写或拒绝 | 动作一致性、约束满足率 |
| 建设性分歧保持修订 | 局部修订以降低风险，同时避免过度中立化 | 人工评测：风险、分歧、建设性、立场、语义、局部性、质量 |
| 指标校准 | 评估自动指标是否反映跨系统的人工判断 | 相关性、排序一致性 |

## 数据格式

```
controgenbench/
├── cases/           # 带上下文的源文本
│   ├── AI-0001.json
│   └── ...
├── claims/          # 提取的主张及文本位置
│   ├── AI-0001.json
│   └── ...
├── annotations/     # 人类标注
│   ├── properties/  # 主张属性标签
│   ├── actions/     # 动作选择
│   └── revisions/   # 修订评测
├── evaluations/     # 系统输出和指标
└── metadata/        # 来源信息、标注者信息
```

每条主张包含：
- `text_span`：在源文本中定位主张的字符偏移
- `properties`：五项核心属性（分歧、建设性、有害性、证据风险、立场）
- `actions`：推荐干预动作及约束
- `revisions`：局部修订及人工评测分数

## 评测方法

### 自动指标

- 主张属性预测：标签分布散度、逐属性准确率
- 动作选择：精确匹配、约束满足率
- 修订质量：COMET 语义相似度、编辑距离、人工对齐度

### 人工评测

系统评测维度：
1. **风险降低**：修订是否降低了潜在危害？
2. **分歧保持**：修订是否保留了有价值的争议？
3. **建设性**：修订后文本是否促进生产性讨论？
4. **立场保持**：作者观点是否忠实保留？
5. **语义保真**：核心含义是否保留？
6. **局部性**：是否避免不必要的改动？
7. **整体质量**：输出的流畅性和自然度
